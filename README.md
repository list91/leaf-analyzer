# Plant Leaf Analyzer

Система для автоматического поиска, сегментации и диагностики листьев растений на фото. Выделяет только больные листья.

## Быстрый старт

1. Установите зависимости:
   ```powershell
   pip install -r requirements.txt
   ```
2. Положите изображения в `images/test`.
3. Запустите детекцию:
   ```powershell
   python tools\detect_leaves.py
   ```
   Результаты будут в `results/detection`.

## Кастомизация
- Порог уверенности: `detection_threshold` в `detect_leaves.py`
- Фильтр по размеру: `min_width`, `min_height` в том же файле

## Обновления структуры проекта (апрель 2025)
- Проведён рефакторинг: тесты перенесены в папку `tests`, утилиты — в `utils`.
- Все импорты обновлены в соответствии с новой структурой (например, используйте `from utils.logger import ...` и `from utils.preprocessing import ...`).
- Для запуска тестов переходите в каталог проекта и используйте:

```powershell
python -m unittest discover tests
```

или запускайте отдельные тестовые скрипты напрямую:

```powershell
python tests/test_model.py
```

- Если возникнут ошибки с импортами, убедитесь, что корень проекта добавлен в PYTHONPATH:

```powershell
$env:PYTHONPATH = "$(Resolve-Path .)"
```

- Для тестов, связанных с cnn_model или cnn_visualize, используйте импорты вида `from tools.cnn_model import ...`.

## Структура
- `tools/` — основные модули (обучение, предсказание, датасет)
- `utils/` — вспомогательные утилиты (логирование, препроцессинг)
- `tests/` — тестовые скрипты
- `images/` — датасеты
- `checkpoints/` — модели
- `results/` — результаты

## Обучение модели (опционально)
```powershell
python tools\cnn_train.py
```
